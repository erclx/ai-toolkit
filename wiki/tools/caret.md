# Caret

[Caret](https://chromewebstore.google.com/detail/caret/bpmdbibldelkpncegllkeegdpblgehgk) is a browser prompt library for Claude, Gemini, and ChatGPT, distributed through the Chrome Web Store. Source: the Caret developer, who publishes and maintains the extension there.

## Capabilities

Typing the trigger symbol in any chat input opens a searchable picker. Select a prompt and it inserts without leaving the keyboard. The trigger defaults to `>`. Prompts are stored in the browser, and syncing from a GitHub repo is available as a manual pull.

## Where it fits

Use it during planning and chat sessions to insert saved prompts without copy-pasting. The trigger picker replaces manual clipboard workflows in Claude chat and Gemini.
