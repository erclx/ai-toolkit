# British spellings `canon markdown audit` reports as findings.
#
# These are not approved project vocabulary. The list covers every such spelling
# appearing in the files the `overrides` entry scopes it to, which is the closed
# set `SPELLINGS` in `src/markdown/bans.ts` plus `analyse`, a word no set carries
# and a comment in that file explains the absence of.
#
# So the list and the shipped set are not the same membership, and neither is
# derived from the other. A spelling added to the set is added here as well, and
# so is one that only a comment or a prose paragraph names.
#
# Add a word here even when the run passes without it. The base dictionary
# accepts a few of these on its own, `centre` among them, so an omission stays
# invisible until that dictionary tightens and then fails a file nobody touched.
#
# An `overrides` entry in `cspell.json` scopes this dictionary to those files by
# name rather than loading it repo-wide. Both surfaces gate a push, so loading it
# everywhere would spell-approve across the whole tree the words the ban gate
# still fails on, leaving the two to disagree about one word. A file that needs
# one of these words is added to that entry.
analyse
behaviour
centre
colour
organise
recognise
summarise
