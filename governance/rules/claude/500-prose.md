# Markdown prose standards

## Authority

- Follow `.claude/standards/prose.md` for voice, language, and the wording of a `title` or `description`. It is the single source.
- Follow `.claude/standards/markdown.md` for headings, lists, code spans, punctuation, emphasis, and file references. It is the single source.
- Read the half that governs the edit before a substantial prose change. Do not work the bans from memory.
- The banned words sit in `prose.md` and the banned characters in `markdown.md`. An edit touching both reads both.
